COREI OS packages

Signed APT repository for Ubuntu 22.04 and 24.04 LTS (amd64).

Install

curl -fsSL https://coreeyegroup.github.io/corei-os/install.sh | sudo sh

Update

sudo apt update && sudo apt upgrade

Channels: stable (tagged releases, default) and edge (every merge to main): curl -fsSL …/install.sh | sudo COREI_SUITE=edge sh

Source: github.com/coreeyegroup/corei-os
